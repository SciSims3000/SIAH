Teaching Sparks

Compact, worthwhile teaching ideas generated during briefings and project work. Each one starts with a real stimulus and ends with a question worth putting in front of students.

The rule

Keep the spark, not the filler.

A Spark is not a complete resource or a production queue. It is a strong teaching move that can be tried, discussed and improved. Sources stay attached so the original evidence is always recoverable.

For future additions

Append the idea, preserve the evidence.

New Sparks are appended to data/teaching-sparks.json using the same fields shown here. Keep the entry compact, include a verified original URL for each useful source, and add it only when the teaching move is genuinely worth keeping.
